## 2. وصف الوظائف (Job Descriptions)

### 2.1 CTO / مؤسس تقني
**المسؤوليات:** المعمارية الكاملة، قيادة الفريق التقني، قرارات build-vs-buy، التواصل مع المستثمرين تقنياً.
**المطلوب:** 8+ سنوات هندسة، خبرة بأنظمة موزّعة، تجربة سابقة بقيادة فريق أو تأسيس، فهم عميق للـLLMs والوكلاء.
**المفضّل:** خبرة سابقة بـDevTools أو أمن أو بنية تحتية.
**الحزمة:** 2-5% أسهم + راتب سوقي.

### 2.2 مهندس Runtime (Rust/Go)
**المسؤوليات:** بناء طبقة تنفيذ الوكلاء المعزولة (sandbox)، دعم gVisor/Firecracker، تحسين الأداء والزمن.
**المطلوب:** خبرة قوية بـRust أو Go، فهم kernel/containers، تجربة بـsandboxing.
**المفضّل:** مساهمات مفتوحة المصدر بـcontainers/runtimes (Firecracker, gVisor, WASM).
**الحزمة:** 0.5-1.5% أسهم.

### 2.3 مهندس أمن (Security Engineer)
**المسؤوليات:** Policy engine، نموذج التهديدات، خرائط الامتثال (SOC2/HIPAA/GDPR)، مراجعة أمنية.
**المطلوب:** خبرة بـOPA/Rego أو policy engines، أمن تطبيقات، فهم الامتثال.
**المفضّل:** شهادات أمنية (OSCP/CISSP)، خبرة بمؤسسات منظّمة.
**الحزمة:** 0.5-1.5% أسهم.

### 2.4 مهندس Backend (Go)
**المسؤوليات:** Control plane API، طبقة البيانات، التكاملات.
**المطلوب:** Go قوي، Postgres، gRPC، أنظمة موزّعة.
**الحزمة:** 0.3-1% أسهم.

### 2.5 مهندس Full-stack
**المسؤوليات:** لوحة التحكم (dashboard)، واجهة المستخدم، تجربة المطوّر.
**المطلوب:** Next.js/TypeScript، Tailwind، تجربة UX للمنتجات التقنية.
**الحزمة:** 0.3-1% أسهم.

## 4. عملية التوظيف (Interview Process)

```
1. مكالمة تعريفية (30 دقيقة)     → توافق الرؤية
2. تمرين تقني حقيقي (4-6 ساعات)  → يبنوا شي فعلي بالكود، مدفوع الأجر
3. مقابلة معمارية (1 ساعة)       → قرارات تصميم
4. اجتماع الفريق (45 دقيقة)      → توافق ثقافي
5. عرض (Offer) خلال 48 ساعة      → سريع، الشركات الكبيرة أبطأ
```

**قاعدة:** تمرين مدفوع الأجر ($500) — يحترم وقت المرشح ويفلتر الجديّين.
