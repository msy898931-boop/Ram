🚀 مشروع AXON

منصة وكلاء AI المؤسسية — خطة العمل الكاملة والبحث السوقي

الإصدار: 1.0 · التاريخ: 2026-10-20 الهدف: بناء أقوى Agent Harness في العالم، قابل للبيع بصفقة كبيرة (Acquisition أو SaaS).

الجزء 0: ملخص تنفيذي (Executive Summary)

الفكرة بكلمة واحدة

AXON = طبقة التحكّم المؤسسية (Control Plane) لكل وكلاء AI في الشركة.

بينما العالم يتسابق على بناء وكلاء (Claude Code, Codex, Cursor)، ما في مين يبيع الحاكم الذي يدير كل هالوكلاء بأمان. هي الفجوة.

ليش هالمشروع بيربح

  • سوق الوكلاء انفجر: Cursor وصلت 29.3 مليار $ تقييم و3 مليار $ إيراد سنوي (ARR)، Cognition (Devin) 4 مليار $.
  • لكن كل المنافسين يحلّون مشكلة "الوكيل الفردي" — ما حد يحل مشكلة "1000 وكيل داخل شركة، بأمان وتكلفة تحت السيطرة".
  • المؤسسات (بنوك، حكومة، صحة) ما بتقدر تشغّل وكلاء AI بدون: تتبّع، صلاحيات، تدقيق، عزل بيانات، وتحكم بالتكلفة. هي = منتجنا.

الخلاصة

نبني منتج open-core: النواة مجانية (لتبني مجتمع)، والمصدر الربحي = الحكم والتحكم والامتثال المؤسسي. هاد اللي الشركات تدفع فيه ملايين، وهو اللي ما في حد عم يبيعه اليوم بشكل كامل.

2.3 الميزة القاتلة (Unfair Advantage)

  1. Model-agnostic بالكامل — تشغّل Claude و GPT و Gemini و Qwen و DeepSeek وأي موديل محلي. المنافسون مقفولين على مزوّد واحد.
  2. Control Plane مو وكيل — ما ننافس الوكلاء، نحكمهم. هاد يعني نقدر نتكامل معهم بدل نحاربهم.
  3. Self-hosted + Air-gapped — للبنوك والحكومة اللي ما بتقبل سحابة.
  4. Governance كمنتج — أول من يبيع "الامتثال للوكلاء" كحزمة جاهزة.

الجزء 3: المنتج (Product)

3.1 الرؤية

"Kubernetes للوكلاء" — كل شركة تشغّل آلاف الوكلاء، وAXON هو طبقة الإدارة.

3.2 المكوّنات الخمسة الأساسية

🧠 1. AXON Core (المحرك — مفتوح المصدر)

  • Harness متعدد الوكلاء: يشغّل Claude Code، Codex، Qwen، أي وكيل.
  • Agent Runtime: تنفيذ معزول (sandboxed) لكل مهمة.
  • Skill/Tool Registry: مكتبة مهارات وأدوات موحّدة (MCP-compatible).
  • Memory Layer: ذاكرة مشتركة بين الوكلاء (vector + graph).
  • الترخيص: Apache-2.0 (لبناء المجتمع والتبنّي).

🛡️ 2. AXON Shield (الحوكمة — مدفوع) 💰

  • Policy Engine: صلاحيات دقيقة (من يقدر يعمل شو، على أي بيانات).
  • Audit Trail: سجل غير قابل للتعديل لكل إجراء اتخذه أي وكيل.
  • Approval Workflows: موافقة بشرية قبل الإجراءات الخطيرة.
  • RBAC/ABAC: أدوار وصلاحيات مؤسسية.
  • الترخيص: BUSL-1.1 — مجاني للاستخدام الداخلي، مدفوع للاستضافة المنافسة، ويتحوّل لـApache-2.0 بعد 4 سنين.

📊 3. AXON Observe (المراقبة — مدفوع) 💰

  • Tracing: تتبّع كامل لكل خطوة (OpenTelemetry native).
  • Cost Control: سقف تكلفة لكل وكيل/قسم/مشروع + تنبيهات.
  • Evaluation Suite: اختبار أداء الوكيل قبل النشر (benchmarks مدمجة).
  • Dashboards: لوحات فورية للـCTO وFinOps.
  • الترخيص: BUSL-1.1 (نفس الشروط).

🔐 4. AXON Vault (أمن البيانات — مدفوع) 💰

  • Secrets Management: مفاتيح API مشفّرة ومركّزية.
  • PII Redaction: إخفاء البيانات الحساسة تلقائياً قبل إرسالها للموديل.
  • Air-gap Deployment: تشغيل كامل بدون إنترنت.
  • Data Residency: تحكم بمكان تخزين ومعالجة البيانات.
  • الترخيص: BUSL-1.1 (نفس الشروط).

☁️ 5. AXON Cloud (السحابة — SaaS) 💰

  • نسخة مستضافة جاهزة (بدون تثبيت).
  • تسعير بالاستخدام + حصص.
  • للشركات الصغيرة والمتوسطة.

ملاحظة ترخيص مهمة: هالطبقات مو أكواد منفصلة — هي نفس الملفات بترخيص تجاري. AXON Core = الملفات تحت Apache-2.0. وTeam/Business/ Enterprise = رخصة تجارية للطبقة تحت BUSL-1.1 (NOTICE بيحدّد الملفات بالاسم). يعني اللي بيتباع هو رخصة + دعم + SLA، مو نسخة برمجية مخفية. الاستخدام الداخلي للطبقة التجارية مجاني أصلاً تحت BUSL؛ الاشتراك بيشتري حقّ الاستضافة المنافسة، والدعم، والتزامات الخدمة.

4.4 استراتيجية البيع (Go-To-Market)

المرحلة 1 (0–6 أشهر): مجتمع مفتوح المصدر - إطلاق على GitHub + HackerNews + Product Hunt. - الهدف: 5,000 نجمة، 50 مساهم، محتوى تقني قوي. - نشر مقارنات "AXON vs Cursor/Claude Code".

المرحلة 2 (6–12 شهر): بيع مبكر (Design Partners) - 20 شركة pilot مجاناً → شهادات (case studies). - التركيز: شركات تقنية متوسطة عندها مشاكل تكلفة/أمان.

المرحلة 3 (12–24 شهر): توسّع مؤسسي - فريق مبيعات + حلول (Solutions Engineers). - شراكات مع مزوّدي سحابة (AWS/Azure/GCP marketplaces). - شهادات: SOC 2 Type II، ISO 27001.

المرحلة 4 (24–36 شهر): سيطرة السوق - Agent Marketplace ناضج. - التوسّع لمنتجات جانبية (AXON for Data، AXON for Security).

  • SaaS بمعدل 10–20x ARR (قطاع AI غالباً 20x+).
  • عند $25M ARR → تقييم $500M–$1B.
  • عند $100M ARR → تقييم $2–3B.

9.3 المعالم المطلوبة لصفقة كبيرة

  1. ARR متنامي (>100% YoY).
  2. عملاء مؤسسيون (logos معروفة).
  3. شهادات امتثال (SOC2, ISO).
  4. مجتمع مفتوح قوي (نجوم + مساهمين).
  5. تقنية يصعب تقليدها (sandbox + policy engine).
